## In a browser with WebMCP

Pages on stanislav-peev.com register these tools through the WebMCP API:

- `get_profile` - his profile as markdown
- `list_research` - published studies with titles, dates and URLs
- `get_page_markdown` - any page of the site as markdown
- `prefill_contact_form` - fills the contact form with the details you pass

`prefill_contact_form` never submits the form. The user reviews the text and
presses the button themselves.
